# Career workspace redesign

Mode: Operate.

User request: redesign the UI to fit a resume-builder and job-application tracker, with particular attention to wide-screen use.

Confirmed direction: light and focused, warm neutrals, forest-green accents, clear data tables.

## Direction contract

- Stable left navigation and a quiet breadcrumb strip frame the working area.
- First viewport: Applications heading, five stage filters with real counts, search/status/sort controls, and a six-column opportunity table. No marketing hero or fabricated metrics.
- Signature interaction: select a role to open its details alongside the table at widths of 1400px and above. On narrower screens the selected details sit above the list, without compressing the table.
- Resume creation: a large job-description pane alongside job details and a selectable experience library, with an explicit action bar and generation status.
- Work history: an experience library beside the new-entry editor.
- Profile: grouped form fields and contextual guidance. Insights: a framed, scrollable Sankey report.
- Preserve drafts, backend contracts, document links, exact statuses, deletion confirmation, and generation sequence.
- No generated imagery is needed for this task-oriented interface.

## Verification limits

BrowserOS MCP is unavailable in this session. No rendered screenshots or browser interaction evidence are available. Production compilation, lint, and source review are valid evidence only for their respective scopes; visual acceptance is pending.

The Impeccable engine is unavailable because its cache cannot be created under the current permissions. The concept tool was attempted and failed. The user's explicit visual direction governs implementation.
