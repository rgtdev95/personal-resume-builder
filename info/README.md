# Project information

Current project documentation for people and coding agents. Read [context.md](context.md) first, then the relevant feature/architecture reference.

| File or folder | Purpose |
|---|---|
| [context.md](context.md) | Current implementation, constraints, verification, and known limitations |
| [features.md](features.md) | Actual screens, workflows, document generation, editing, and printing |
| [architecture.md](architecture.md) | Stack, source layout, schema, API, frontend state, and data boundaries |
| [privacy-review.md](privacy-review.md) | Pre-commit review scope, protections, and historical exposure |
| decisions/ | Dated historical decisions; superseded details are not current implementation instructions |
| notes/ | Sanitized project notes, without personal career data or credentials |
| research/ | External references and summaries |
| archive/ | Historical material; review for personal information before tracking it |

Root [AGENTS.md](../AGENTS.md) provides agent-neutral development instructions. [PRODUCT.md](../PRODUCT.md) defines product constraints and [DESIGN.md](../DESIGN.md) records the implemented visual system. Personal resumes and raw career records belong in ignored private/, not in tracked documentation.
